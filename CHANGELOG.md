# Changelog

## 0.3.0 - 2026-11-07

- A pretotype plan that counts an action, and does not count a survey.
- Positioning in a fixed order: alternatives, difference, value, who cares, category.
- A six-pattern failure check with no score.
- Source files for the two readings we can keep, and notes for the rest.

## 0.2.0 - 2026-11-07

- Eight genres, with a different proof and a different test for each.
- A people map from live search, with no standing list of communities.
- An unsent interview note, one follow-up, and a call script.
- A pass-or-fail test on the critique.
- A way to start from complaints when there is no idea yet.
- Founder reach on the brief.
- A debrief that runs only on notes you paste.

## 0.1.0 - 2026-11-07

First release.

- Orchestrator plus skills for clarifying, ideating, researching, critiquing, and drafting.
- Scene, competition, and critic agents.
- Claim tags for facts, inferences, assumptions, and unknowns.
- A stop after the verdict, before any pitch is written.
- Spoken script, memo, and deck outline as markdown.
