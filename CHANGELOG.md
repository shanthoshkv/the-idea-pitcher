# Changelog

## 0.2.0 - 2026-11-07

- Eight genres, with a different proof and a different test for each.
- A people map from live search, with no standing list of communities.
- An unsent interview note, one follow-up, and a call script.

- A way to start from complaints when there is no idea yet.
- Founder reach on the brief.
- A debrief that runs only on notes you paste.
